# 🧮 Calculadora (Web & Terminal)

Uma calculadora simples desenvolvida em HTML, CSS e JavaScript, com suporte para interface web e execução via linha de comandos (Node.js).

## 🚀 Funcionalidades
- **Versão Web**: Interface gráfica interativa, suporte para teclado físico, visor deslizante e prevenção de erros.
- **Versão Terminal**: Execução via CLI utilizando a biblioteca `prompt-sync`.

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript (ES6+)
- Node.js & npm

## ⚙️ Como Executar

### Versão Web
Basta abrir o ficheiro `index.html` em qualquer navegador.
